# Safety boundaries

This repository is a public engineering demonstration. It contains only
synthetic names, processes, documents and fictional guidance.

The agent is read-only. It does not approve or reject claims, initiate
payments, send messages, call a client API or mutate official status. Human
review and decision handoff are explicit internal stages, with append-only
audit events and unresolved evidence preserved.

The system intentionally has no tool for changing `official_status`, no
payment tool, no email tool and no production integration. A recommendation
review records a human evaluation of the recommendation, not approval or
rejection of the synthetic claim.
